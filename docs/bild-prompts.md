# Bild-Prompts — The Sausage Guy

12 Bilder fehlen. Jeden Prompt einzeln in ChatGPT einfügen, das Bild
herunterladen, unter dem angegebenen Dateinamen speichern. Einbauen mache ich.

**Wichtig:** kein Text, keine Schrift, keine Logos im Bild. Wenn ChatGPT trotzdem
Buchstaben hineinmalt, einmal nachfassen mit "remove all text and lettering".

Bildformat immer **querformat / landscape** anfragen — ich schneide danach auf
die richtige Größe, also lieber etwas Luft am Rand lassen.

Kategorieseiten greifen die Bilder automatisch ab, sobald sie da sind.
